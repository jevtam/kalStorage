# Лаболаторная работа №2
Вторая лабораторная работа по веб-разработке: создание интерактивного To-Do List приложения с использованием HTML, CSS, JavaScript и локального хранилища браузера (LocalStorage).

Приложение поддерживает создание, редактирование, удаление и сохранение задач, а также отображает список задач с адаптивным интерфейсом под мобильные устройства.
## Структура
index.html - основная страница приложения

js/main.js  - логика приложения

styles/tokens.css - цветовые переменные, радиусы, тени, базовые значения

styles/base.css - общие стили и layout страницы

styles/components.css - стили кнопок, карточек задач, модальных окон

styles/app.css - специфические стили To-Do приложения

img - изображения
## Функциональные возможности
Создание задачи

Отображение задач

Редактирование задачи

Удаление задачи

Сохранение задач
