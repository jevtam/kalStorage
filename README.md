# Лаболаторная работа №3
Третья лабораторная работа по веб-разработке: перенос функционального приложения To-Do List на React.
Основная цель - повторить архитектуру и логику, но реализовать все с использованием компонентного подхода и хуков React.

Приложение поддерживает создание, редактирование, удаление и сохранение задач, а также отображает список задач.
## Структура
index.html - точка входа Vite

src/styles/tokens.css - цветовые переменные, радиусы, тени, базовые значения

src/styles/base.css - общие стили и layout страницы

src/styles/components.css - стили кнопок, карточек задач, модальных окон

src/styles/app.css - специфические стили To-Do приложения

src/App.jsx - основной компонент приложения

src/main.jsx - ReactDOM рендер

src/index.css - базовые сбросы Vite

punlic/img - изображения
## Функциональные возможности
Создание задачи

Отображение задач

Редактирование задачи

Удаление задачи

Сохранение задач
